Outcome Measures
Define custom outcome TSV files if your paradigm does not use standard RT / Accuracy measures (e.g. game score, distance, frequency). Leave empty to use BEEHub defaults (RT + ACC + ACCBIN).
How it works

Each entry generates an outcome_measures array in the JSON. The pipeline discovers TSV files by suffix (e.g. _SCORE_beh.tsv) and reads values from column (e.g. score). Standard RT/ACC outcomes are used automatically if you leave this section empty.
