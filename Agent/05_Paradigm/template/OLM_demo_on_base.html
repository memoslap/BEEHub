OLMM

Object-Location Memory — interactive demo

What this is
A browsable version of the OLM paradigm. You learn which houses belong at which map positions, with feedback after every trial, then a memory test.

How it works

1 A house appears at a position on the map.
2 Decide whether it is in the correct place.
3 Feedback shows the true position, so you learn it.
4 A 3-choice memory test follows.
← yes, correct place
→ no, wrong place

Note
This demo runs a handful of trials. The full paradigm uses 4 learning blocks of 28 stimuli, each repeated 4 times, plus 2 control blocks — 336 trials.
