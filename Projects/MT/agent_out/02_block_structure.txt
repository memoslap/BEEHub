BLOCK LABELS vs. SEQUENCE
  Block numbers are not sequential 1–8. They are labelled 4, 5, 7, 8,
  10, 11, 13, 14 — suggesting each block may be a "run" within a larger
  experimental session with gaps (possibly for breaks, other tasks, or
  stimulus presentation structure).  Whether these correspond to a
  known design (e.g., 8 runs interleaved with other stimuli) is a
  question for the experimental protocol.

TRIAL_COUNT COLUMN
  Column "trials_count" = 60 for every single row across all 48 blocks.
  Actual row counts per block range 433–524.
  → trials_count does NOT reflect the number of data rows in the block.
    Likely denotes the number of trials per trial_type level in the
    original design (60 go + 60 nogo = 120 design trials per block),
    but the compiled file contains many rows per trial — likely
    fixation / fixation cross / stimulus presentation / ITI samples
    captured at a high sampling rate (e.g., mouse position logged
    continuously).

ROWS PER TRIAL — HIGH SAMPLING RATE
  Expected design trials per block: ~468 (go) + ~117 (nogo) = ~585
  Actual rows per block: 433–524, averaging ~480.

  However, the trials_count column = 60 for ALL rows.
  This is inconsistent with actual row counts (no match: 48/48 mismatches).

  Two likely interpretations:
    A) Each "trial" generates one row → trials_count = 60 is wrong /
       refers to something else (e.g., number of digit presentations
       of a specific type).
    B) Each trial generates multiple rows (e.g., mouse cursor sampled
       at each frame), and trials_count = 60 is the number of
       "target" trials of one type.

  The ratio of actual_rows / 60 ranges 7.2–8.7, suggesting ~7–9 rows
  per "trial_count" unit.  This could be per-digit presentations
  (8 digits × ~6 = 48 trials → not matching), or it could indicate
  that each trial is logged at multiple timepoints.

  RECOMMENDATION: inspect a few rows from one block to see whether
  mouse_resp.x/y/time vary within the same trial_type/correct_response
  (indicating repeated sampling) or are constant (indicating one row
  per trial).  See Prompt 3 for that investigation.
