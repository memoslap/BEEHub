================================================================================
SOURCE DATA COLUMNS (from 1a_go_nogo_dm_...csv header)
================================================================================

The last 4 columns of the source CSV are:
  participant, session, date, expName

These appear on every row (including welcome/instruction rows) and encode:
  - participant: raw participant ID from filename (e.g., "001", "012")
  - session: session letter (e.g., "a", "b")
  - date: acquisition date (e.g., "2025-04-30")
  - expName: experiment name ("go_nogo_dm")

These are SESSION-level metadata, NOT demographics. No age, sex, handedness,
or screening info is recorded in the source data.

================================================================================
CONCLUSION
================================================================================

NO per-participant demographics file exists for the MT project.

What exists:
  - Source CSVs contain 4 session-level metadata columns: participant, session,
    date, expName. These identify which participant/session/date a session
    belongs to, but carry no demographic info.
  - 5 xlsx files in paradigm/psychopy/ are all condition/block tables (stimulus
    lists and block sequence). None contain participant or demographic data.
  - No participants.tsv, no Excel demo sheet, no SPSS savefile, no screening
    form, no handedness questionnaire, no Edinburgh Handedness Inventory file.
  - MT_description.json has no demographics.
  - Convert/ directory has no data files.

Missing (not found anywhere in repo):
  - Age / sex / gender distribution
  - Handedness / Edinburgh Handedness Inventory
  - Screening questionnaire results
  - Session dates (beyond the filename-derived date in source CSVs)
  - Exclusion list (beyond "participants 2 and 4 incomplete, ses-01 only")
  - Recruitment information

These must be obtained from the PI or external sources. The MT project has
no structured demographic data recorded in the repository.
