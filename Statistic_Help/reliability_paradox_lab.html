The core idea in three lines

1. Group effects are easy to detect when people are similar to each other: the effect is large relative to the spread across people.

2. Individual-differences research needs the opposite: people must differ reliably from each other, otherwise ranking them is meaningless.

3. A task tuned to produce a robust group effect tends to shrink between-person variance — so the very same property that makes it “robust” makes it a poor tool for correlational work.

ICC = σ²between / ( σ²between + σ²error )

1 · Robust effect, unreliable individuals

Each simulated person has a true effect (e.g. Stroop/flanker cost in ms). We “test” them in two sessions; each session adds measurement noise from a finite number of trials.

true effecti ~ N(μ, σb²)  ·  observedi,s = truei − shift·[s=2] + ei,s  ·  SD(e) = σtrial·√(2/k)
ICCagreement = σ²participant / ( σ²participant + σ²session + σ²error )  ·  ICCconsistency = σ²participant / ( σ²participant + σ²error )

The “session shift” models something like a practice effect: everyone changes by the same amount, which lowers agreement-type ICC but not consistency-type ICC or Pearson's r. The variance-component bar below is estimated from the simulated data via a two-way ANOVA.

2 · How many trials would you need?

More trials shrink measurement error, but if between-person spread is tiny, the required number explodes.

ICC(k) = σ²b / ( σ²b + 2σ²trial/k )  ⇒  kneeded = 2σ²trial·ICC / ( σ²b·(1−ICC) )
Reliability against trials per condition, for your σb (thick) and for half / double that spread (thin).

From the supplement (section D, as I read it): the authors subsampled trials from their own data and found that, at the 40 trials per condition used in earlier flanker reliability studies, the reliability of the RT and error costs ranged from negative values to about .6. They conclude that estimates based on so few trials are insecure, and that this matters most when between-person variance is low. My curve above is an idealised model, not a reproduction of their analysis.

3 · Difference scores: high reliability in, low reliability out

Effects like “incongruent − congruent” are difference scores. When the two conditions are highly correlated, most of what people share cancels — leaving mostly noise.

rdiff = ( ½(rAA + rBB) − rAB ) / ( 1 − rAB )  (equal-variance case)

4 · Unreliable measures shrink correlations (and your power)

If you correlate a task score with something else, the observed correlation is capped by the reliability of both measures.

robserved = rtrue · √( relX · relY )  ·  N80% ≈ ( (1.96 + 0.84) / atanh(r) )² + 3
disattenuated r = robserved / √( relX · relY )  (capped at ±1)

The Stroop cost is the mildest case here. Sample sizes and 95% intervals are in the supplement; the intervals are wide, so treat single values as rough.

Assumptions & limits of this simulation

  • The true effect of each person is perfectly stable between sessions; real-world change over time would lower test–retest reliability further.
  • Trial-level noise is normal, independent, and equal for all people and conditions.
  • ICC here is ICC(2,1) in the Shrout & Fleiss sense (two sessions, agreement form) computed from the simulated data; the consistency form leaves session variance out of the denominator. The “formula” value assumes no session shift.
  • Power uses a Fisher-z normal approximation; the simulated power uses the same critical value. Both are approximations.
  • Rule-of-thumb reliability labels are conventions, not laws.
